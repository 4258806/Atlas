# Glassmorphism Enhanced Personal 0.0.1

独立版本 `0.0.1`，正式发布，日期：2026-11-17。来源为 Enhanced v1.2.1，基线提交 `0332d5f7c73f7994ba21c01e4b739d04835120b1`。本次按用户最终确认，覆盖路线第 1–3 步。

## 本版范围

- 工程流程：受保护 PR、非修复质量检查、浏览器回归、生产原生 ZIP 和绑定准确源码的验收记录。
- 独立重置时间：每台节点分别设置 IANA／固定偏移时区、每月日期及小时／分钟；处理夏令时、月底与旧配置迁移。后台保留相应参数编辑，原始流量计数器和历史不清零。
- 金额与汇率：节点价格、月均与剩余价值保持节点输入币种，不受顶栏币种选择影响；首页顶栏按已有 API 汇率将全部金额统一换算到选定的单一币种。保留原有选择、缓存与手动覆盖，校验有效期和备用源缺失币种；无报价时明确显示不可用，不能按 1:1 混加。自定义币种标签原样保留，只有 API 有相应报价时才能参与换算。

前台布局、地球／地图、原有样式及默认显示属性保持 fork 原样。新增时区／时分仅位于原管理页的逐节点参数区域。汇率来源链接复用原汇率说明位置，不新增顶栏行。未开发三网排序、方块／波浪线切换、TCP／UDP 显示开关或回程采集扩展。

## 下载与安装

安装附件为 `komari-theme-Glassmorphism-build-<short-sha>.zip`，顶层结构为 `komari-theme.json`、`preview.png`、`dist/`。`SHA256SUMS.txt` 和 `theme-build-verification.json` 记录文件校验值、版本及准确源码提交。GitHub 自动生成的 Source code ZIP 不是主题安装包。

先在 Komari 后台导出／备份现有主题配置，保留当前主题的 ZIP 与数据备份，然后在主题管理上传本 Release 的原生 ZIP，启用并检查节点参数、金额和刷新后的保存状态。本版本继续使用主题标识 `Enhanced`；若现用其他标识，应按后台支持的方式复制配置后切换。0.0.1 为个人 Fork 的独立版本序列，不能按数字大小与上游 1.2.1 混为同一更新渠道。

用户自行在 CA 后台上传切换，本次发布不修改生产。回滚时上传此前保存的主题 ZIP，并恢复对应配置备份；不要删除节点、计数器或历史数据库。

## 验证与边界

验证目标为官方 Komari Server **1.6.1**。测试使用真实官方隔离后端、实际 ZIP 上传／启用、桌面和手机、配置持久化、原生流量历史查询、升级及回滚；节点价格和历史是明确的合成测试数据，汇率为实际公共 API 访问。没有把 fixture 通过宣称为生产账单或真实硬件验收。具体源码、结果与包 SHA256 绑定在 [验收记录](verification/acceptance-0.0.1.json)。正式附件由手动受控 CI 构建，发布后下载并校验实际文件。

流量周期依赖服务端保留足够且覆盖边界的历史；历史不足时显示不足，不伪造完整账单。汇率是费用参考报价，并非银行成交价。首选 [ExchangeRate-API](https://www.exchangerate-api.com/docs/free)，备用 [Frankfurter](https://frankfurter.dev/)，不新增原始汇率再分发服务。保留上游 MIT、原作者及第三方声明。
