# Atlas v0.0.4 · TcpQuality 对比与集成

用户授权的替换范围为回程采集和对应面板，并明确要求纳入现有 Komari 目录、无独立服务、每小时执行；本轮仅 DMIT。

| 项目       | 0.0.3 固定目标采集               | 0.0.4 Komari 附件                                   |
| ---------- | -------------------------------- | --------------------------------------------------- |
| 目标       | 每城三个固定目标，实际只测上海   | TcpQuality 三网目标目录，分别保留 31 省份观测       |
| 判定       | 简短逐跳 ASN、严格保守分类       | 原样保留固定版本上游的 IP／ASN 线路标签，并注明来源 |
| 分项       | IPv4 TCP／UDP                    | IPv4、IPv6、UDP 两地址族、IPv4 大包分别存储         |
| 缺失与差异 | 未达目标／协议分歧               | 不可用、Hidden／失败、混合省份、协议差异不互相替代  |
| 运行       | 独立 Helper 单次服务             | Komari 附件前台命令，复用 cron；原生租约一小时一期  |
| 接收       | 原生节点身份、固定三个 POST 路径 | 同一鉴权／路径；新结果与旧证据分开持久化            |
| 公开       | ASN 摘要                         | 无 IP 的线路／省份汇总；显式开启，完整调试仍私有    |

附件报告中的普通 IPv4／UDP 为三网 CN2GIA，大包有少量 `163`、`163->4837`，因此不能把一个概览结论填充到所有分项。本版本显示采集器实际分类，不提供运营商商业认证。DMIT 当前缺少 IPv6 默认路由，IPv6 记录不可用，不凭 IPv4 推断 IPv6。

上游：[ibsgss/TcpQuality](https://github.com/ibsgss/TcpQuality/tree/db52fc60523320fc4a34b5c369f28be38df21d13)。单独 `vendor/` 保存原始 GPL 源码、许可和 SHA256 锁，MIT 适配层只调用程序并解析结构化 CSV。既有旧版方法文档描述历史适配，不能覆盖本版授权／结论。

节点向上游查询目标和公网响应跳的 ASN，不上传完整报告或排名。Komari 凭据不传入上游进程。仅原生后台保存当前摘要及调度租约；原始 CSV、IP、日志在节点私有附件目录。默认保留 24 个本附件产生且带所有权标记的运行目录。
