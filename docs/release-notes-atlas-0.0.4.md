# Atlas v0.0.4

三网回程改用 Komari TcpQuality 附件，以各协议／省份的实际线路观测替换固定目标 ASN 摘要。TcpQuality 源码固定为 `db52fc60523320fc4a34b5c369f28be38df21d13`，保留 GPL-3.0-only，作为单独附件调用；MIT 主题及原生插件不复制它的线路分类函数。

首页回程块采用参考图的三行玻璃面板：运营商标记、线路徽标、等级／混合状态和更新时间，保持已保存的三网顺序。展开可分别查看 IPv4、IPv6、UDP IPv4／IPv6、IPv4 大包的省份分组。单一概览不代表所有协议／省份完全相同，不强制填入 CN2GIA；未测、不可用、混合、时间异常及过期均明确显示。

附件归入现有 Komari／Komari Agent 目录，通过原生逐节点鉴权与既有 POST poll/result 接口工作，无新监听端口、独立常驻服务或 systemd 单元。现有 cron 只检查是否到期，服务端持久化租约控制实际一小时采集一次。首次仅接入 DMIT，其他十台不变。IPv6 缺少连接时如实记录不可用，不改网络来制造结果。

仅运行三网回程及上述分项，关闭上游报告上传、排名、测速、国际／教育网测试。原始 CSV／调试记录仅保留在节点私有目录；公共投影没有原始 IP、凭据或租约。旧采集证据另存保留，现有金额、独立流量重置、三网排序、TCP/UDP 显示开关及地球／地图不变。

兼容 Komari 1.6.1；节点附件需要 Linux 和 Python >=3.12。主题 ZIP、原生插件 ZIP、Komari 附件 ZIP 各自独立，不能混装。部署前保留旧 ZIP、配置及私有备份；回滚先停用附件调度和该节点的 collector 策略，再恢复匹配旧版本。精确源码、实测限制、安装包校验和升级／回滚记录见本 Release 附件。合成预览不是生产网络测量。
