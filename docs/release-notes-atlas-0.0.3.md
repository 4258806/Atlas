# Atlas v0.0.3

当前路线的收尾版本：保留独立流量重置、本币节点金额／单币种汇总、三网排序及显示开关；首页原三块指标下新增 TCP/UDP 块，右侧两格显示三网回程。

回程采用独立 Komari 插件与节点本地 Helper。首页只读取已有结果，不执行探测；按已保存三网顺序显示，点击展开目标、ASN、时间及不确定状态。未采集显示未测，过期或证据不足不伪装成有效线路。公共摘要必须由管理员显式开启，仅公开 ASN，不含逐跳 IP、凭据或租约；原始证据仍受管理员认证保护。

主题管理「线路与延迟」开启「显示回程线路」「首页双格回程块」「消费已采集的自动结果」「连接回程伴生插件」。旧配置默认保留原回程位置；所有未知字段、费用、重置参数及流量历史保留。地图和地球不变。仅更新主题不等于安装采集端。

实际兼容目标为 Komari Server 1.6.1。插件安装 ZIP 与 Helper ZIP 分别下载、安装，不能当作主题 ZIP 上传。Helper 的原生 Agent 身份只保存在节点私有文件中，不进入主题包、命令行或公开记录。DMIT 仅执行用户授权的一轮；服务为单次执行，不启动定时采集，其他节点未接入。

正式源码、CI、安装包 SHA256、DMIT 实测及升级／回滚记录见本 Release 附件和 docs/verification/acceptance-0.0.3.json。安装前保留 Atlas v0.0.2 ZIP 并备份配置；回滚主题重新上传原 ZIP，插件和采集端独立停用，不删除节点、历史或配置。保留 MIT、上游及 Transit 来源声明。ASN 路径观测不是运营商商业线路认证。
