# Atlas v0.0.3

- 首页新增 TCP／UDP 连接块，旁侧双格显示三网回程。
- 接入独立插件与节点 Helper，按原生节点身份采集和保存结果。
- 支持运营商排序、展开详情、未测／过期状态及显式开启的公开摘要。

已验证兼容 Komari Server 1.6.1。主题 ZIP 只包含原生皮肤；插件／TcpQuality 在[组件页](components.md)单独下载。精确源码、SHA256、安装和回滚说明见 [Release](https://github.com/MagnetOscar/Atlas/releases/tag/atlas-v0.0.3) 与[下载索引](downloads.md)。
